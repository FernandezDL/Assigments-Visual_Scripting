# Assigments-Visual_Scripting
Assigments for the Visual Scripting for Unity Class at VFS

## Assigment 1
Move the character with WASD

Jump with space

Collect the 10 coins with E before the 2 minute timer ends to win the game

## Assigment 2
### Main Menu
This menu is displayed when the game starts and includes 3 buttons:
- Play: Starts the game and switches input mode to gameplay
- Options: Opens the options menu where the audio settings can be modified
- Quit: Closes the application

### HUD
The HUD is created at game astrt and displays the remaining time you have to complete the game

### Pause menu
The pause menu is opened by pressing the `Q Key` during the gameplay and it includes 3 buttons:

- Resume Game: Closes the pause menu and resumes the gameplay
- Main Menu: Returns to the main menu level
- Quit game: Exits the application

### Audio System
There's a music track that is spawned once when the level is setup and is controlled globally.

#### Volume control
In the options menu theres a slider that adjusts the music volume
